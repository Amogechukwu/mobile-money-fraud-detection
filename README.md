# Mobile Money Fraud Detection

> An end-to-end data analysis project using Excel, SQL, Power BI and Python.

## In plain English
Mobile money lets people send and receive money using a phone. A small number
of these transactions are fraud (someone stealing money). This project
analyses 6.3 million transactions to find out **what fraud looks like**,
and builds a tool that **warns when a transaction looks suspicious**.
